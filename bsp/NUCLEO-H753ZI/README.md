# NUCLEO-H753ZI

STM32H753ZI (Cortex-M7, rev V), UART3 (PD8/PD9) via on-board ST-LINK VCP, 115200-8N1.

## Requirements

- arm-none-eabi-gcc
- cmake >= 3.13
- openocd

## STM32 Vendor Files (not in the repository)

`Drivers/CMSIS/` and `Drivers/STM32H7xx_HAL_Driver/` are vendor code and are
not committed to the repository; `Outputs/` is generated by the build. Only
`Drivers/BSP/` (board drivers) is tracked.

Get the vendor files from the
[STM32CubeH7](https://github.com/STMicroelectronics/STM32CubeH7) firmware
package (v1.13.0 = HAL V1.11.6; the HAL and CMSIS device trees are git
submodules, so a plain clone is not enough) and copy them in:

```sh
git clone --depth 1 --branch v1.13.0 https://github.com/STMicroelectronics/STM32CubeH7.git /tmp/STM32CubeH7
git -C /tmp/STM32CubeH7 submodule update --init --depth 1 \
    Drivers/CMSIS/Device/ST/STM32H7xx Drivers/STM32H7xx_HAL_Driver
cp -r /tmp/STM32CubeH7/Drivers/CMSIS                bsp/NUCLEO-H753ZI/Drivers/
cp -r /tmp/STM32CubeH7/Drivers/STM32H7xx_HAL_Driver bsp/NUCLEO-H753ZI/Drivers/
```

CI does the same automatically (see `.github/workflows/bsp/nucleo-h753zi.json`).

The build needs at least:

```
Drivers/
├── CMSIS/
│   ├── Include/                          # core_cm7.h, cmsis_gcc.h, ...
│   └── Device/ST/STM32H7xx/
│       ├── Include/                      # stm32h753xx.h, ...
│       └── Source/Templates/
│           ├── system_stm32h7xx.c
│           └── gcc/startup_stm32h753xx.s
└── STM32H7xx_HAL_Driver/
    ├── Inc/
    └── Src/
```

## Build

Run from the repository root. Re-run the first command after adding new source files (CMake uses GLOB).

```sh
cmake -S bsp/NUCLEO-H753ZI -B build/NUCLEO-H753ZI -DCMAKE_BUILD_TYPE=Debug -DCMAKE_EXPORT_COMPILE_COMMANDS=ON
cmake --build build/NUCLEO-H753ZI -j
```

Outputs: `bsp/NUCLEO-H753ZI/Outputs/Firmware{,.hex,.bin}`

## Flash

```sh
openocd -f interface/stlink.cfg -f target/stm32h7x.cfg \
  -c "program bsp/NUCLEO-H753ZI/Outputs/Firmware verify reset exit"
```

## Serial

Connect to the ST-LINK USB port (CN1) at 115200-8N1:

```
Hello Nerd RTOS!
nerd@rtos:~$ help
```

`ps` lists threads, `load` shows CPU load, `test_*` run the in-tree test suites.
